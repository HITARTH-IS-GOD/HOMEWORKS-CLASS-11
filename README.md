# Class 11 CS Homework Archive

This repository stores all daily Class 11 CS homework pages.

How to use it daily:
1. Open `generator.html` in a browser.
2. Enter the homework date, title, and paste the Python code.
3. The page generates the final HTML for that homework.
4. Copy the entire HTML from the preview area.
5. Go to GitHub and create a new file in the `pages/` folder.
6. Name it like `2026-11-02.html` (use the date in `YYYY-MM-DD` format).
7. Paste the HTML into the file and commit it.
8. Add a link to that homework page in `index.html` and commit again.
9. The live website updates automatically through GitHub Pages.

Important:
- This repo is designed to be a daily homework archive website.
- Your teacher only needs the same website link every day.
- GitHub Pages is free and works from this repo.
